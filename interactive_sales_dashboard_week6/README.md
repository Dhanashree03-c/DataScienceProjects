## Interactive Sales Dashboard

## Project Overview

The Interactive Sales Dashboard is a data analytics application built using **Python, Seaborn, Plotly, and Streamlit**.

The objective of this project is to:

- Analyze sales trends over time
- Evaluate product performance
- Understand regional revenue contribution
- Perform customer segmentation
- Apply statistical visualization techniques
- Build a professional, interactive analytics dashboard

This project demonstrates:
- Data preprocessing
- Statistical visualization
- Interactive dashboard development
- Modular code architecture
- Production-level project organization
